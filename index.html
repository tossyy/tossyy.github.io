Digital History Uploader

A personal, non-commercial command-line tool that uploads videos to its operator's own YouTube channel, which publishes explainer videos on the history of computing.

This tool uses YouTube API Services.

  • Privacy Policy: https://tossyy.github.io/privacy-policy.html
  • Terms of Service: https://tossyy.github.io/terms-of-service.html
  • YouTube Terms of Service: https://www.youtube.com/t/terms
  • Google Privacy Policy: https://www.google.com/policies/privacy

How it works

  1. The channel owner authorizes the tool once with Google OAuth 2.0, using only the youtube.upload scope.
  2. For each finished video, the tool uploads the video file with its title, description, and tags (videos.insert) and sets its thumbnail (thumbnails.set).
  3. The returned video ID is stored locally to avoid duplicate uploads.

The tool runs only on the operator's own computer and is not offered to other users.
