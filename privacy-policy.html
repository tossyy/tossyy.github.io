Privacy Policy — Digital History Uploader

Last updated: 2026-10-06

Digital History Uploader is a personal, non-commercial command-line tool that uploads videos produced by its operator to the operator's own YouTube channel. It uses the YouTube API Services.

By using this tool, you agree to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms

Terms of Service of this tool: https://tossyy.github.io/terms-of-service.html

Google's handling of data is described in the Google Privacy Policy: https://www.google.com/policies/privacy

Who uses this tool

The tool is used only by its operator, on the operator's own computer, for the operator's own YouTube channel. It is not offered to other users and does not request authorization from any other Google account.

What information the tool accesses

  • An OAuth 2.0 access token and refresh token for the operator's Google account, with the scope https://www.googleapis.com/auth/youtube.upload.
  • No other user data is requested. The tool does not read viewer data, comments, subscriber lists, or analytics.

How the information is used

  • The tokens are used only to call videos.insert (upload a video with its title, description, and tags) and thumbnails.set (set the video's thumbnail).
  • The ID of each uploaded video is saved locally so the same video is not uploaded twice.

Storage and sharing

  • The tokens are stored only on the operator's computer, in a file readable only by the operator's user account. They are never sent to any server other than Google's.
  • No information obtained through the YouTube API Services is shared with any third party.
  • The tool does not use cookies, analytics, or advertising.

Revoking access and deleting data

Access can be revoked at any time from the Google Account permissions page: https://security.google.com/settings/security/permissions

Deleting the local token file removes all stored authorization data. The tool stores no other data obtained from the YouTube API Services.
